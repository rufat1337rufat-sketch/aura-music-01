# Aura Music (Android)

Музыкальный плеер в WebView с медиа-виджетом на экране блокировки и в шторке.

## Как получить APK через GitHub

1. Создайте на GitHub новый репозиторий (ветка `main`).
2. Загрузите в него все файлы из этой папки вместе с папками `app` и `.github`.
   Папка `.github` скрытая: если при перетаскивании она не попала в репозиторий,
   создайте файл через Add file → Create new file с именем `.github/workflows/build.yml`
   и вставьте в него содержимое из этого проекта.
3. Откройте вкладку Actions → Build APK. Сборка запускается сама после загрузки файлов
   (или кнопкой Run workflow) и занимает несколько минут.
4. Когда сборка закончится, откройте её и скачайте `AuraMusic-APK` из раздела Artifacts.
   Внутри будет `app-debug.apk`: распакуйте архив и установите файл на телефон
   (разрешите установку из неизвестных источников).

## Сборка в Android Studio

Откройте папку проекта в Android Studio и нажмите Build → Build APK(s).

## Что где

- `app/src/main/assets/index.html` сам плеер.
- `MainActivity.kt` WebView, выбор файлов, кнопка «Назад».
- `AuraBridge.kt` приём данных о треке из страницы.
- `MediaService.kt` MediaSession и уведомление с кнопками для экрана блокировки.
- `PlayerHub.kt` общее состояние.

## Важно

- Музыку добавляйте кнопкой «Добавить музыку» или «Выбрать файлы»: выбор папки с автосканом
  в WebView не работает, там выбираются файлы.
- На Android 13 и новее разрешите приложению уведомления, иначе виджет не появится.
- Оформление карточки на экране блокировки задаёт оболочка телефона.
- Package по умолчанию `com.example.auramusic`. Чтобы сменить, поправьте его в
  `app/build.gradle.kts`, `AndroidManifest.xml` и в начале каждого `.kt` файла,
  а папки `java/com/example/auramusic` переименуйте так же.
